Create terraform directory
- Create parent folder 07-week-07/ via the following command in the vsCode terminal => mkdir 07-week-07
- Create a sub folder under 07-week-07/ named terraform/ via the following command in the vsCode terminal => mkdir terraform
- Change directory into terraform/ => cd terraform

Create 0-auth.tf
- Create 0-auth.tf inside of terraform/ => touch 0-auth.tf
- Open the following webpage for the terraform registry => https://registry.terraform.io/providers/hashicorp/google/latest/docs
- Click USE PROVIDER (purple button)
- Copy and Paste the terraform block and provider block (under Terraform 0.13+) into 0-auth.tf
- Replace # Configuration options WITH project = "class75-michaelanunda" (gcloud config get-value project)
- Below project = "class75-michaelanunda" SET region = "us-central1" (https://registry.terraform.io/providers/hashicorp/google/latest/docs/guides/provider_reference)
- Save 0-auth.tf

Execute the following terraform commands for 0-auth.tf in the given order:
1. terraform init
2. terraform validate
3. terraform fmt
4. terraform plan
5. terraform apply -auto-approve
