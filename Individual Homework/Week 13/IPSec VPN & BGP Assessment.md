## 1: According to RFC 4301, what is the primary purpose of IPSec?

A. To replace DNS servers B. To secure IP communications through authentication and encryption C. To accelerate TCP throughput D. To replace BGP routing

**B. To secure IP communications through authentication and encryption**

## 2: According to RFC 7296, which protocol version is used for modern IKE negotiation?

A. IKEv0 B. IKEv1 C. IKEv2 D. ESPv2

**C. IKE v2**

## 3: Which UDP port is primarily used for IKE / ISAKMP negotiations?

A. UDP 179 B. UDP 500 C. UDP 443 D. UDP 3389

**B. UDP 500**

## 4: According to RFC 3948, which UDP port is commonly used for NAT Traversal (NAT-T)?

A. UDP 22 B. UDP 80 C. UDP 4500 D. UDP 161

**C. UDP 4500**

## 5: What is the primary purpose of a Pre-Shared Key (PSK) in IPSec?

A. To assign BGP routes B. To authenticate VPN peers C. To encrypt DNS traffic D. To replace ESP encryption

**B. to authenticate VPN peers**

## 6: Which IPSec component is responsible for encrypting data traffic?

A. AH B. ESP C. BGP D. ICMP

**B. ESP**

## 7: What is the purpose of the Cloud Router in GCP?

A. Encrypt traffic B. Replace the VPN Gateway C. Exchange BGP routing information D. Perform DNS resolution

**C. Exchange BGP routing information**

## 8: Which RFC defines the Encapsulating Security Payload (ESP)?

A. RFC 4303 B. RFC 4271 C. RFC 1918 D. RFC 1035

**A. RFC 4303**

## 9: Which protocol and port are used by BGP?

A. UDP 500 B. TCP 179 C. TCP 443 D. UDP 161

**B. TCP 179**

## 10: What is the purpose of the 169.254.x.x addresses used in HA VPN BGP sessions?

A. Public Internet routing B. DNS failover C. Link-local BGP peer communication D. DHCP assignment

**C. Link-local BGP peer communication**

## 11: According to RFC 4271, what is the purpose of BGP?

A. Encrypt VPN traffic B. Dynamically exchange routing information C. Replace TCP D. Manage DNS records

**B. Dynamically exchange routing information**

## 12: What is the most common cause of Phase 1 IPSec failures?

A. MTU mismatch B. Incorrect VM subnet C. PSK mismatch D. DNS timeout

**C. PSK mismatch**

## 13: Which of the following is typically configured on both VPN peers?

A. Different PSKs B. Different BGP peer IPs on same side C. Matching encryption settings D. Random ASN values

**C. Matching encryption settings**

## 14: Which GCP component creates the public IP addresses used by the VPN tunnels?

A. Cloud DNS B. HA VPN Gateway C. Cloud NAT D. VPC Firewall

**B. HA VPN Gateway**

## 15: What BGP session state indicates successful route exchange?

A. Idle B. Connect C. Active D. Established

**D. Established**

## 16: Which IPSec protocol uses IP Protocol 50?

A. AH B. ESP C. BGP D. NAT-T

**B. ESP**

## 17: Why do companies commonly deploy dual HA VPN tunnels?

A. To increase DNS speed B. For redundancy and failover C. To eliminate BGP D. To disable encryption

**B. For redundancy and failover**

## 18: What is the primary purpose of NAT Traversal (NAT-T)?

A. Compress VPN traffic B. Encrypt DNS queries C. Allow IPSec traffic through NAT devices D. Replace ESP headers

**C. Allow IPSec traffic through NAT devices**

## 19: Which of the following best describes a Security Association (SA)?

A. A DNS forwarding table B. A set of agreed IPSec security parameters C. A static route table D. A load balancer policy

**B. A set of agreed IPSec security parameters**

## 20: What is the correct order of IPSec and BGP establishment?

A. BGP → IPSec → IKE B. IKE Phase 1 → IPSec Phase 2 → BGP C. NAT-T → DNS → ESP D. Firewall → DNS → BGP

**B. IKE Phase 1 → IPSec Phase 2 → BGP**
