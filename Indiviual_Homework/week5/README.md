##### Terraform IVPAD Sequence - Screenshots
This repository contains the screenshots of each step in the Terraform IVPAD 
sequence as well as the resulting outputs from running the required commands.
Required Screenshots:
1. Terraform init & date/hostname/whoami - Screenshot of the terraform init command and
the date && hostname && whoami output (all in one file).

2. Terraform validate - Screenshot of the terraform validate command output.
3. Terraform plan - Screenshot of the terraform plan command output.
4. Terraform apply - Screenshot of the terraform apply command output.
5. Terraform destroy - Screenshot of the terraform destroy command output.

##### Prerequisites:

Make sure you have the following tools installed:
- Terraform
- Git Bash (Windows) or Terminal (Mac/Linux)
- Google Cloud Platform (GCP) account for managing resources.

How to Run the Commands:
0. Run the following:
```date && hostname && whoam```
1. Initialize Terraform:
```terraform init```
2. Validate the configuration:
```terraform validate```
3. Create the execution plan:
```terraform plan```
4. Apply the configuration:
```terraform apply```
5. Destroy the resources:
```terraform destroy```


##### Deliverables:

The screenshots of each step will be available in this repository.
