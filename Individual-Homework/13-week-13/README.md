# GCP Virtual Private Network Academics

This repository contains material that relates to Virtual Private Network (VPN) in Google Cloud Platform (GCP). Academic reading assignments covered various VPN concepts, including types of VPNs, configuration, and best practices for secure and efficient network connectivity in GCP.

A comparison between legacy GCP Classic VPN services and the improved GCP High Availability VPN service is included. The comparison document can be found in the file named `GCP_ClassicVPN_versus_HA_VPN.md`.


Within this repository is an academic assessment that includes questions and answers related to IPSec, BGP, and VPN technologies used globally.  The assessment can be found in the file named `IPSec_VPN_BGP_Assessment.md`.
